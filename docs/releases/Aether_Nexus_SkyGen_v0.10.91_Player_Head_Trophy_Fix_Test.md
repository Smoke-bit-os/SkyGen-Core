# Aether Nexus SkyGen v0.10.91

**Player Head Trophy Fix test build**

[Bedrock add-on](../../releases/Aether_Nexus_SkyGen_v0.10.91_Player_Head_Trophy_Fix_Test.mcaddon) · [Matching source ZIP](../../releases/Aether_Nexus_SkyGen_v0.10.91_Source.zip)

Newly placed player head trophies save their location. Trophy displays resist knockback, stop drifting, and cannot damage players. Pick up and re-place an older trophy to save a new anchor if it was already displaced.

## Testing

Trophy regression checks passed on Bedrock Dedicated Server 1.26.63.1. A PvP kill produced a named trophy that was handed to the player whose head it depicted. The checks covered anchoring, simulated upward movement and damage, crouch recovery, pickup permissions, and behavior after a server restart. Xbox and Realms testing is pending.
