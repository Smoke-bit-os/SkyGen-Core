# SkyGen Core roadmap

## Milestone 1 — Safe world and navigation

- Spawn platform, initial player rescue, three reserved hotbar tools
- Teleport warm-up, visible countdown, cancellation, timeout cleanup and cooldown
- Safe plot allocation, generation, and protection
- Bedrock multiplayer testing and versioned package

## Milestone 2 — Economy and generators

- Persistent Credits and Orbits balances (18,000,000 Credits = 1 Orbit)
- Physical generator eggs, placement, upgrades and persistence
- Server shop and transaction validation

## Milestone 3 — Social systems

- Player marketplace with escrow and secure trading
- 50 ranks, rank labels above players, progression and benefits

## Release criteria

A milestone is not complete until tested inside Minecraft Bedrock, including a fresh void world and reconnect/rejoin cases.
